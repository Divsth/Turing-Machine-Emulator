Machine definition

One edge per line: q0 -> q1 : 0 -> 1, R means "from q0 to q1, read 0, write 1, move right". The shorthand 0 -> R (keep the symbol) also works and is shown in full. b is blank. A missing transition rejects. Anything after // is a comment. Edit, then press Load.

Steps vs. input length

Runs the machine in the definition box once for each n = 1…N, using the selected preset's input generator (for Custom, the input is n zeros). This measures steps on one input per length, which shows the trend for that family of inputs. It does not prove a worst-case bound.
